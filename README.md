<h2 align="center">📌 Overview</h2>

Relax is a creative, interactive spiritual website that transforms ordinary cursor movement into a visually engaging devotional experience.

As visitors move their cursor, spiritual elements such as **ॐ (Om), Radha, and Ram** follow its path, creating a distinctive visual interaction. On touch-enabled devices, the experience can use finger movement to create similar interactions.

The website combines spiritual animations, devotional sounds, and theme selection to create a personalized digital environment.

With Shiv selected as the default theme and options to explore Ram and Radha Krishna, Relax brings together spirituality, motion, sound, and modern frontend development.

<h2 align="center">🕉️ Spiritual Themes</h2>

Relax offers three devotional experiences, each with its own spiritual identity, visual elements, and associated audio.

### 🔱 Shiv Experience

- Selected by default when the website opens.
- Features an atmosphere inspired by Lord Shiva.
- Incorporates Om-inspired cursor effects.
- Provides the associated Om sound.

### 🏹 Ram Experience

- Offers a devotional atmosphere inspired by Lord Ram.
- Features Ram-themed cursor-following elements.
- Provides the corresponding Ram devotional sound.

### 🦚 Radha Krishna Experience

- Creates an experience inspired by Radha and Krishna.
- Features Radha-themed cursor-following elements.
- Provides the corresponding Radha Krishna devotional sound.

Switching between themes lets visitors explore different devotional experiences through coordinated visuals and audio.

<h2 align="center">🖱️ Interactive Cursor & Touch Experience</h2>

One of Relax's defining features is its spiritual motion-based interaction.

### 🖥️ Desktop Experience

- **Om Cursor Effect:** Om symbols appear along the mouse's path.
- **Ram Cursor Effect:** Ram-themed elements create a dynamic visual trail.
- **Radha Cursor Effect:** Radha-themed elements follow mouse movement.
- **Motion-Based Animation:** Cursor movement becomes part of the visual experience.
- **Theme-Based Effects:** The selected spiritual theme determines the corresponding visual atmosphere.

### 📱 Mobile Experience

- Supports touch-based interactions on compatible devices.
- Finger movement can trigger spiritual visual effects.
- Adapts the interaction for touchscreens without requiring a physical mouse.
- Provides a mobile-friendly way to explore the experience.

<h2 align="center">🎵 Theme-Specific Audio Experience</h2>

Sound plays an important role in making each devotional theme feel distinct.

### Audio Features

- **🔱 Shiv Audio:** Devotional sound associated with the Shiv theme.
- **🏹 Ram Audio:** Devotional sound associated with the Ram theme.
- **🦚 Radha Krishna Audio:** Devotional sound associated with the Radha Krishna theme.
- **🔊 Sound Enablement:** Visitors can enable sound to experience the audio.
- **🎨 Theme Synchronization:** Changing the selected theme updates the associated devotional experience.
- **📱 Cross-Device Audio:** Designed to support desktop and mobile browsers, subject to browser playback restrictions.

### How It Works

1. Open Relax with Shiv selected as the default theme.
2. Enable sound to begin the audio experience.
3. Move the mouse on desktop or your finger on a touch-enabled device to interact with the spiritual visual effects.
4. Switch between Shiv, Ram, and Radha Krishna to explore the corresponding devotional visuals and sounds.

Audio playback behavior may vary depending on browser policies and device settings.
